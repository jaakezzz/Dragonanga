Dragonanga - play and analyse (Windows, 64-bit)
===============================================

1. Unzip the whole folder anywhere (do not run it from inside the zip).
2. Double-click play_dragonanga.exe.

No installation is needed. If Windows SmartScreen says "Windows protected your PC", click
"More info" and then "Run anyway" - the program is not code-signed.

The Dragonanga engine (dragonanga-engine.exe) is in the same folder. It needs a CPU with SSE4.1 and
POPCNT (any 64-bit PC from about 2009 on).
